# GiftLab — Robux Gifting Simulator

A responsive React + TypeScript fan-made gifting simulator concept.

## Features
- Local demo account registration and login
- Selectable virtual gift packages
- Simulated gift confirmation (no payment)
- Gift history stored in the current browser
- Responsive layout with Tailwind CSS
- Inter typography and #1978E5 accent color

## Important demo limitations
GiftLab is not affiliated with Roblox. It does not connect to Roblox accounts, send Robux, process payments, or represent official Robux pricing. All amounts and values are fictional. Demo account data is stored locally in the browser and is not production-grade authentication. Do not use a real password.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The production build is generated in `dist/`.
